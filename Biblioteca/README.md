# Biblioteca

Proyecto de práctica con Tkinter y SQLite.

## Archivos

- `main.py`: punto de entrada de la aplicación.
- `interfaz.py`: ventanas y controles gráficos.
- `base_datos.py`: conexión y consultas a SQLite.
- `ejercicio_tkinter_sqlite_biblioteca.pdf`: enunciado del ejercicio.

Los módulos están preparados para empezar a trabajar; todavía no contienen la solución del ejercicio.
